# 🛠 Информационная система управления автосервисом (CRM)

Веб-приложение для автоматизации работы автосервисного предприятия. Система поддерживает разграничение прав доступа для четырех ролей пользователей и автоматизирует полный цикл обработки заявок на ремонт.

## 👥 Ролевая модель
1. **Клиент:** Регистрация/авторизация, добавление собственных автомобилей, создание заявок на ремонт, отслеживание статусов, редактирование профиля.
2. **Мастер:** Управление новыми заявками, назначение ответственных механиков, формирование перечня необходимых услуг.
3. **Механик:** Просмотр назначенных заявок, изменение статусов выполнения работ (в работе, ожидание запчастей, завершено), оформление запросов на закупку деталей.
4. **Администратор:** Полный контроль над системой, управление учетными записями сотрудников, каталогом услуг и запчастей, просмотр аналитики и выгрузка отчетов в формате Excel (`.xlsx`).

## ⚙️ Архитектура и особенности разработки
- Реализована модульная структура и MVC-подобный подход.
- Безопасность: хеширование паролей (`PASSWORD_BCRYPT`), проверка сессий, защита от SQL-инъекций через подготовленные выражения.
- Транзакционная обработка данных в MySQL для критически важных операций (создание заявок, назначение сотрудников).
- Генерация отчетов на стороне сервера с использованием библиотеки `XlsxWriter`.

## 🗄️ Технологический стек
- **PHP** (серверная логика, контроллеры, обработчики)
- **MySQL** (реляционная база данных, внешние ключи, связи)
- **HTML5 / CSS3** (интерфейсы)
- **Visual Studio Code, Git**
